xcrossDocsIntroduction

Introduction

xcross runs and debugs cross-platform (Flutter / CMP) iOS apps on a real iPhone, natively from Windows or Linux. No Mac required.

xcross builds, signs, installs, launches and debugs Flutter and Compose Multiplatform iOS apps on a real iPhone, straight from Windows or Linux. No Mac, no Xcode.

Windows / Linuxyour machine
Flutter or CMPyour project
xcrossbuild · sign · launch
iPhoneiOS 17+

Limits#

ImportantDevices need iOS 17+. Flutter runs are debug (JIT) only, since release/AOT needs gen_snapshot on macOS. There is no Simulator run mode.
