How it works

Two frameworks. One tool. Zero Macs.

xcross reimplements the iOS build, signing and CoreDevice launch pipeline in pure Dart, on top of the official Swift and LLVM toolchains.

Flutterhot reload · DAP
Compose MPfast rebuild loop
xcross Windows · Linux
iPhone · iOS 17+

New in 2.0

A rebuilt core, and a lot more of it.

xcross 2.0 is a major reimplementation. Here is what changed for you.

2.0

Offline signing

After the first online run, xcross signs from cached profiles. XCROSS_OFFLINE=1 skips Apple entirely.

Read more 2.0

Your real App ID

Pick the original bundle id or an XCR- one on first run. Saved to the project, so CI agrees.

Read more 2.0

ARM64 hosts

Native Windows ARM64 builds, signing and self-update, next to Linux arm64.

Read more 2.0

Native SwiftPM

SwiftPM resolves the whole plugin graph itself. No clones, no rewritten Package.swift.

Read more 2.0

SwiftUI + #Preview macros

SwiftUI, Previews and FoundationModels macros expand through a prebuilt Open Apple Macros server.

Read more 2.0

Per-framework doctor

flutter doctor and compose doctor check only what each needs, grouped by section.

Read more

Capabilities

Everything you need on the device.

Hot reload for Flutter, fast restart for Compose

Flutter gets the full r / R loop. Compose gets --watch: rebuild, reinstall, relaunch, with cached Kotlin/Native builds.

Native on Windows & Linux

Real debugging

Breakpoints and DevTools in VS Code or JetBrains through DAP.

Your Apple ID, even offline

Quick start

Four commands to a running app.

  1. 1

    Set up the host

    $xcross setup
  2. 2

    Extract the iOS SDK (once)

    $xcross sdk install ~/Downloads/Xcode.xip
  3. 3

    Sign in with an Apple ID

    $xcross auth --apple-id you@example.com
  4. 4

    Tunnel + run

    $xcross tunnel && xcross flutter run
  1. 1

    Set up the host + Kotlin/Native

    $xcross setup && xcross compose setup
  2. 2

    Extract the iOS SDK (once)

    $xcross sdk install ~/Downloads/Xcode.xip
  3. 3

    Sign in with an Apple ID

    $xcross auth --apple-id you@example.com
  4. 4

    Tunnel + run

    $xcross tunnel && xcross compose run --watch
