IDE integration

One command sets up VS Code or JetBrains to run, hot reload and debug on an iPhone.

One command per project, per IDE. Both drive the same debug adapter as the CLI.

Your IDEF5 / Debug
xcross DAPxcross flutter dap
VM Servicebreakpoints · reload
iPhonerunning app

NoteIDE debugging (breakpoints, DevTools, hot reload buttons) is Flutter only today. Compose apps run from the terminal with xcross compose run --watch.

Setup#

xcross ide vscode
# then press F5 on "xcross: iOS device"
xcross ide idea
# install LSP4IJ, then Debug "xcross: iOS device"

Good to know#

Coexists with FlutterConfigs without "xcross": true go to Flutter's own adapter.
Several iPhonesAdd "args": ["--udid", "<UDID>"] to the launch entry. Re-runs keep it.
After upgrading xcrossRe-run xcross ide vscode to refresh the shim path.
JetBrains Run buttonDon't use Flutter's own button. It calls flutter run, which fails off-macOS.
