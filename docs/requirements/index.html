Requirements

What your Windows or Linux host, your iPhone and your project need before running Flutter or Compose Multiplatform apps with xcross.

Host#

Tool
Flutter
Compose
Get it
Swift 6.4+
swift.org
LLVM + ld64.lld
releases.llvm.org
Python 3 + pymobiledevice3
via xcross setup
Xcode.xip (once)
xcodereleases.com
Flutter SDK
flutter.dev
JDK 21+
any vendor
Kotlin/Native
via compose setup

ImportantInstall Swift 6.4 or newer first (on macOS, the Swift paired with your Xcode). setup, sdk install and the doctors reject older swift.org toolchains. xcross sdk install patches the SDK for the active Swift toolchain, so switching Swift later means re-running it.

Per host#

# Runs the winget, Scoop or Chocolatey setup script (asks which if several),
# or direct.ps1 when none is installed. Each package is confirmed first:
# VS Build Tools, Swift, LLVM, Python, then pymobiledevice3.
xcross setup
xcross setup --manager winget   # pick one explicitly
# Install Swift from swift.org (swiftly is easiest), then:
xcross setup   # apt / dnf / pacman: clang, lld, usbmuxd, pipx, pymobiledevice3
# On Windows: attach the iPhone to WSL
usbipd attach --wsl --busid <BUSID>
# Inside WSL: same as Linux
xcross setup

Windows: Apple drivers#

USB access needs Apple’s drivers. Install both from Apple, not the Microsoft Store:

iTunesApple Mobile Device driver + service.iCloudApple Application Support for sign-in and pairing.

No need to sign in to either. Reconnect the iPhone and tap Trust This Computer.

Device#

Physical iPhoneNo Simulator support.
iOS 17 or laterRequired for the CoreDevice launch path.
USB or Wi-FiWi-Fi after a one-time pairing. See wireless.

Host architectures#

Release
Flutter
Compose
Windows x64
Windows ARM64
Linux x86_64
Linux aarch64

Compose’s Kotlin/Native compiler only ships for x64 hosts on Windows and Linux. The Windows installer picks the native ARM64 build even from an emulated x64 PowerShell.

Check it all at once with xcross flutter doctor or xcross compose doctor.
